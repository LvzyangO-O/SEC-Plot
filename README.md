# SEC 曲线绘图工具操作指南

这是一个用于绘制分子排阻层析（SEC）曲线的图形化工具，适用于从 Cytiva AKTA/UNICORN 导出的 CSV 文件。

程序会根据 CSV 第二行的 `UV` 和 `Fraction` 标记自动识别数据所在的列，因此 UV 数据位于第 1–2 列或第 3–4 列均可正常读取。

## 1. 文件说明

- `sec_plot_gui.py`：完整的图形界面程序。

`sec_plot_gui.py` 需要 Python 以及 `numpy`、`matplotlib` 两个第三方库。

## 2. 首次安装

推荐使用 Python 3.12（64 位）。安装 Python 后，在 PowerShell 中运行：

```powershell
py -m pip install numpy matplotlib
```

如果提示已经安装（`Requirement already satisfied`），无需重复安装。

## 3. 启动程序

程序启动后显示两个主要区域：

- 左侧：数据与绘图参数；
- 右侧：图片预览。

可以拖动两个区域中间的分隔线，调整参数区和预览区的宽度。

## 4. 导入 CSV

### 导入一个文件

点击曲线卡片中的“选择…”按钮，然后选择 AKTA 导出的 CSV 文件。

程序会自动使用 CSV 文件名作为曲线名称。

### 一次导入多个文件

点击“批量导入 CSV…”，在文件选择窗口中按住 `Ctrl` 或 `Shift` 选择多个 CSV，再点击“打开”。

每个文件会建立一条独立曲线，并自动分配不同颜色。导入后仍可单独修改每条曲线的名称和颜色。

### 增加或删除曲线

- 点击“+ 添加空白曲线”增加一个数据位置；
- 点击曲线卡片右侧的“删除”移除该曲线；
- 至少会保留一条曲线。

## 5. 曲线名称与颜色

- “名称”决定图例中显示的文字；
- 可直接填写十六进制颜色，例如 `#1464F4`；
- 也可以点击“选色”打开颜色选择器。

多条曲线可以分别设置名称、颜色和填充范围。

## 6. 设置填充区域

每条曲线支持两种填充方式，两种方式可以同时使用。

### 按 Fraction 孔位填充

1. 先选择该曲线的 CSV 文件；
2. 点击“选择孔位…”；
3. 在 96 孔板界面中勾选需要用于后续实验的孔；
4. 点击“确定”。

按钮会显示当前选择数量，例如“选择孔位…（4 孔）”。只有 CSV 中实际存在的 Fraction 孔位可以勾选。

### 按洗脱体积填充

在“体积填充”输入框中直接填写范围，例如：

```text
8-10
```

多个不连续范围使用英文或中文逗号分隔：

```text
8-10, 12.5-13.2
```

单位为 mL，范围起点必须小于终点。

## 7. 实时预览与保存

参数修改后，预览会在约 0.45 秒后自动刷新。实时预览不会自动写入文件。

- “刷新预览”：立即按照当前参数重新绘图；
- “保存图片…”：选择文件路径和格式后才会导出图片。

支持的格式：

- PNG：适合 PowerPoint、Word 和常规图片使用；
- PDF：适合论文排版和矢量打印；
- SVG：适合 Illustrator、Inkscape 等矢量编辑软件。

## 8. 图片标题与坐标轴标题

### 文字内容

- “标题”：整张 SEC 图的标题；
- “X 轴标题”：默认 `Elution volume (mL)`；
- “Y 轴标题”：默认 `UV absorbance (mAU)`。

所有文字都可以自行修改，也可以将标题留空。

### 标题位置

“标题 X / Y”使用坐标区域的相对位置：

- `X = 0.5`：水平居中；
- `Y = 1.02`：位于绘图区上方；
- `X = 0.5, Y = 0.90`：标题位于绘图区内部；
- X 越小越靠左，越大越靠右；
- Y 越小越靠下，越大越靠上。

### 坐标轴标题位置和距离

- X 轴标题位置：左侧、居中或右侧；
- Y 轴标题位置：下方、居中或上方；
- “距离”越大，坐标轴标题离坐标轴越远；
- 默认距离为 `8` point；
- 常用的加宽距离约为 `12–18`；
- 负值可以将轴标题向绘图区方向移动。

## 9. 坐标范围与刻度

### 显示局部曲线

如果只希望显示 8–20 mL：

- X 范围最小值填写 `8`；
- X 范围最大值填写 `20`。

Y 范围使用同样方法。一个坐标轴的最小值和最大值必须同时填写；全部留空时由程序自动选择范围。

### 主刻度与次刻度

“X 主 / 次刻度”和“Y 主 / 次刻度”分别包含两个输入框：

- 左侧输入框：主刻度间隔；
- 右侧输入框：次刻度间隔。

例如，X 主刻度填写 `2`、次刻度填写 `0.5`，表示每 2 mL 显示一个主要刻度，每 0.5 mL 显示一个较短的小刻度。

留空时使用 Matplotlib 自动刻度。

## 10. 字体、字号和加粗

- “字体”：设置全图字体；
- “刻度数字字号”：设置 X/Y 轴数字大小；
- “标题字号”：只设置图片标题大小；
- “轴标题字号”：只设置 X/Y 轴标题大小；
- “标题加粗”：只加粗图片标题；
- “轴标题加粗”：加粗 X/Y 轴标题。

论文作图时，标题和轴标题通常可以比刻度数字大 1–3 pt。

## 11. 图例位置

默认位置为固定“右上”，因此改变窗口大小时图例不会自动跳到另一侧。

可选位置包括：

- 自动（最佳位置）；
- 右上、左上、右下、左下；
- 图外右侧；
- 自定义；
- 隐藏。

“自动（最佳位置）”会根据当前画布大小和曲线位置动态调整，因此普通窗口、全屏预览和导出图片中的位置可能不同。

选择“自定义”时，需要填写图例 X/Y。常见示例：

```text
X = 0.80
Y = 0.85
```

X/Y 通常使用 0–1 的坐标轴相对值，但也可以填写该范围之外的数值，将图例放到绘图区外。

## 12. 图片尺寸、DPI 与透明背景

### 图片尺寸

“宽 × 高”单位为厘米。默认值：

```text
18.8 × 12.2 cm
```

这决定最终导出图片的实际版面比例。

### DPI

- 150 DPI：快速预览或屏幕使用；
- 300 DPI：一般论文和报告；
- 450 DPI：较高质量输出，默认值；
- 600 DPI：高分辨率印刷。

PDF 和 SVG 是矢量格式，曲线与文字可以无损缩放；DPI 主要影响其中的栅格化内容。

### 透明背景

- 不勾选：输出白色背景；
- 勾选“透明背景”：预览和导出均使用透明画布。

透明 PNG 或 SVG 适合叠加到 PowerPoint、Illustrator 或其他带颜色的版面中。

## 13. 推荐操作顺序

1. 导入一个或多个 CSV；
2. 设置曲线名称和颜色；
3. 选择 Fraction 孔位或填写洗脱体积范围；
4. 设置 X/Y 显示范围；
5. 修改标题、轴标题、字体和字号；
6. 设置主刻度、次刻度及图例位置；
7. 检查右侧实时预览；
8. 点击“保存图片…”选择 PNG、PDF 或 SVG。

## 14. 常见问题

### 提示找不到 `UV` 或 `Fraction`

程序要求 CSV 第二行包含 `UV` 和 `Fraction` 标记。请确认文件是 AKTA/UNICORN 的原始 CSV 导出格式，没有在 Excel 中删除顶部信息行。

### 提示未读取到 UV 或 Fraction 数据

可能原因包括：

- CSV 内容不完整；
- 文件编码或分隔格式被其他软件修改；
- 选择的不是原始 AKTA CSV；
- UV/Fraction 标记后面没有成对的数据列。

### 找不到需要选择的孔位

孔位选择器只显示 CSV 内实际存在、且名称类似 `6.A.1` 的 Fraction。如果某个孔未出现在导出文件中，就不会显示为可选。

### 图例在不同窗口尺寸下移动

将图例位置设置为固定的“右上”等位置。只有“自动（最佳位置）”会根据预览区域动态移动。

### 界面内容显示不全

- 拖动参数区和预览区中间的分隔线；
- 手动增大窗口或最大化；
- 曲线数量较多时，使用数据区域右侧的滚动条。

### `py` 或 `python` 命令不可用

关闭并重新打开 PowerShell后再次尝试。如果仍不可用，请确认 Python 已安装，并在安装时启用了命令或 PATH 支持。

### 缺少 Matplotlib 或 NumPy

运行：

```powershell
py -m pip install numpy matplotlib
```

## 15. 数据安全说明

程序只读取选中的 CSV 文件，不会修改原始数据。只有点击“保存图片…”后，才会在指定位置创建或覆盖输出图片。
